# Topology generation

This directory contains the Mathematica/FeynArts code used to generate the tree-level topologies accompanying the project

**Opening up baryon-number-violating operators**

by Julian Heeck, Diana Sokhashvili, and Anil Thapa.

## Contents

- `Generate_topologies.nb` — Mathematica notebook used to generate the tree-level topologies.
- The accompanying FeynArts model file — model definitions required by the notebook.

## Requirements

The notebook requires:

- [Mathematica](https://www.wolfram.com/mathematica/)
- [FeynArts](https://feynarts.de/)

The FeynArts model file in this directory must be available to FeynArts when running the notebook. Depending on your local FeynArts installation, either place the model in the appropriate FeynArts `Models` directory or adjust the model path used in the notebook.

## Pre-generated topology files

Pre-generated results are available from the project website:

https://julian-heeck.github.io/BNV/

These include:

- `topology_files.zip` — Mathematica topology files;
- `topology_text_files.zip` — text representations of the topologies;
- `topology_pdfs.zip` — PDF versions of the topology diagrams.
